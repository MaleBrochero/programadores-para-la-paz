## 🕊️ Sobre el Proyecto
**Programadores para la Paz** es una iniciativa de formación integral que fusiona el desarrollo de software y la tecnología con la creación de soluciones comunitarias, participativas y constructivas. A lo largo del programa, diseñamos y construimos herramientas que promueven el acceso transparente a la información, la convivencia digital responsable, la participación ciudadana activa y la construcción sistemática de una cultura de paz.

---

## 📂 Estructura del Repositorio

El repositorio está organizado en **6 módulos temáticos**, cada uno dividido en semanas formativas. Cada semana contiene archivos de texto con respuestas, ejercicios prácticos, diseños y reflexiones.

---

### 📘 Módulo 1 — Tecnologías de la Comunicación y Desarrollo de Aplicaciones Web

Introducción al mundo del desarrollo web y la programación, desde los algoritmos más básicos hasta la comunicación entre cliente y servidor.

| Semana | Contenido |
|--------|-----------|
| **semana1** | Introducción a la programación, algoritmos básicos, diagramas de flujo y primeras reflexiones cívicas sobre el uso de la tecnología para la paz. |
| **semana2** | Comandos avanzados de terminal, control de versiones con Git y GitHub, maquetación con HTML y estilos CSS en cascada. |
| **semana3** | Estructuras de control en JavaScript (arreglos, ciclos `for` y `while`), fundamentos de comunicación cliente/servidor y servidores HTTP con Node.js (peticiones GET y POST). |

---

### 📙 Módulo 2 — Comunicación Digital para la Paz y la Democracia

Construcción de servidores y APIs con Node.js y Express para gestionar información comunitaria de forma estructurada.

| Semana | Contenido |
|--------|-----------|
| **semana4** | Primer servidor con Node.js y Express. Creación de rutas GET, configuración de proyecto con `npm init` y `npm install express`. |
| **semana5** | Rutas y endpoints avanzados en Express. Métodos HTTP GET y POST, parámetros dinámicos en rutas e introducción al concepto de API. |

---

### 📗 Módulo 3 — Construcción de Comunidades Digitales para la Participación Ciudadana

Procesamiento de datos ciudadanos a través de APIs Express, aplicando metodologías ágiles para construir soluciones comunitarias reales.

| Semana | Contenido |
|--------|-----------|
| **semana6** | Recepción y procesamiento de datos JSON con `req.body` en Express. Rutas POST para registro de información comunitaria e incidencias ciudadanas. |
| **semana7** | APIs con almacenamiento en memoria usando arrays. Rutas GET y POST para registrar y consultar reportes ciudadanos en tiempo real. |

---

### 📕 Módulo 4 — Sistemas Operativos de Código Abierto y Seguridad Digital

Fundamentos de Linux y buenas prácticas de seguridad digital aplicadas a plataformas de participación ciudadana.

| Semana | Contenido |
|--------|-----------|
| **semana8** | Comandos básicos de Linux (`uname -a`, `whoami`, navegación de directorios), buenas prácticas de seguridad digital y protección de plataformas comunitarias. |
| **semana9** | Servidores con Node.js y Express en entornos Linux: gestión de puertos, logs del sistema y componentes de estabilidad para aplicaciones comunitarias. |

---

### 📓 Módulo 5 — Desarrollo de Software para la Construcción de Espacios Digitales Democráticos

Metodologías ágiles, diseño de bases de datos, autenticación de usuarios y protección de datos en plataformas ciudadanas.

| Semana | Contenido |
|--------|-----------|
| **semana10** | Metodología ágil aplicada: diseño de backlog con historias de usuario priorizadas, definición de iteración (Sprint 1), criterios de aceptación y definición de "terminado". Automatización de alertas con n8n y Telegram para un sistema de veeduría digital. |
| **semana11** | Diseño de modelo de datos relacional con 4 entidades (Usuario, Causa, Apoyo, Reporte_Seguimiento). Diseño de interfaz de usuario (formularios, vistas, componentes). Autenticación con login seguro (bcrypt, tokens). Protección de datos personales y reflexión sobre responsabilidad ética en plataformas democráticas. |

---

### 📒 Módulo 6 — Infraestructura Técnica y Desarrollo de Plataformas Digitales para la Participación Ciudadana

Reto final integrador: el sistema **"Petición en 3 Clics"**, que conecta backend, base de datos, generación de documentos PDF y automatización para apoyar causas comunitarias.

| Semana | Contenido |
|--------|-----------|

## 🛠️ Tecnologías Utilizadas

| Área | Tecnologías |
|------|-------------|
| **Backend** | Node.js, Express Framework, REST APIs, JSON |
| **Frontend** | HTML5 semántico, CSS3, Vanilla JavaScript (`fetch`, `async/await`, DOM) |
| **Bases de datos** | Diseño relacional, entidades, claves primarias y foráneas |
| **Seguridad** | Bcrypt, autenticación con tokens, cifrado de contraseñas, minimización de datos |
| **Automatización** | n8n, Telegram Bot API |
| **Generación de documentos** | PDF generado automáticamente desde plantillas del sistema |
| **Sistemas Operativos** | Linux, comandos de terminal, seguridad en servidores |
| **Control de Versiones** | Git, GitHub |

## 📌 Principios que guían este trabajo

- 🔒 **Privacidad por diseño:** Solo se almacena y transmite la información estrictamente necesaria.
- 🌐 **Acceso abierto:** Las plataformas deben ser accesibles para cualquier ciudadano, sin importar su nivel técnico.
- 🤝 **Participación ciudadana:** La tecnología es una herramienta al servicio de la comunidad, no al revés.
- 🕊️ **Construcción de paz:** Cada solución técnica está pensada para fortalecer la convivencia y la democracia.
