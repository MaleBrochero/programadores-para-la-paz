# Programadores para la Paz - Universidad de Cartagena

¡Hola! Este es el repositorio de mi trabajo para el curso **Programadores para la Paz**, como parte de mi formación en la Universidad de Cartagena.

## 🕊️ Sobre el Proyecto
**Programadores para la Paz** es una iniciativa que busca integrar la tecnología y el desarrollo de software con la creación de soluciones comunitarias y participativas. A lo largo del curso, aprendemos a construir plataformas digitales que promuevan la transparencia, la participación ciudadana y el acceso a la información, utilizando herramientas modernas de programación.

## 📂 Estructura del Repositorio
Este repositorio está organizado por semanas de estudio. Dentro de cada carpeta se encuentran los ejercicios prácticos, bitácoras de comandos, scripts en JavaScript y reflexiones teóricas correspondientes a cada módulo:

- **📁 semana1**: Introducción a la programación, algoritmos básicos y conceptos fundamentales.
- **📁 semana2**: Comandos de terminal, control de versiones con Git y GitHub, y desarrollo de los primeros scripts.
- **📁 semana3**: Estructuras de datos en JavaScript (Arrays), ciclos (`for`, `while`), y conceptos básicos de cliente/servidor (HTTP, GET, POST) usando Node.js para plataformas de participación.

## 🛠️ Tecnologías Utilizadas
- **JavaScript** (Lógica de programación, arreglos, ciclos)
- **Node.js** (Servidores básicos HTTP)
- **Git y GitHub** (Control de versiones)
