Responde con tus propias palabras.

1. ¿Qué es fetch?

Respuesta: Es una función nativa de JavaScript que nos permite realizar solicitudes HTTP asíncronas desde una página web en el navegador hacia un servidor remoto o local para obtener o enviar datos sin necesidad de recargar la página completa.

2. ¿Para qué sirve fetch en una página web?

Respuesta: Sirve como canal de comunicación en tiempo real entre el cliente y el servidor. Permite actualizar dinámicamente partes de la pantalla trayendo nueva información (p. ej., avisos) o registrando datos del usuario (p. ej., propuestas) de manera instantánea.

3. ¿Qué significa que el cliente consulte información al servidor?

Respuesta: Significa que el navegador del usuario envía una petición (comúnmente una solicitud GET) a una ruta o API del servidor para que este le devuelva información que la página web pueda leer y mostrar en la pantalla.

4. ¿Qué ruta se usa para consultar la campaña?

Respuesta: Se utiliza la ruta GET `/api/campania`.

5. ¿Qué ruta se usa para consultar avisos?

Respuesta: Se utiliza la ruta GET `/api/avisos`.

6. ¿Qué ruta se usa para enviar propuestas?

Respuesta: Se utiliza la ruta POST `/api/propuestas`.

7. ¿Qué método se usa para consultar información?

Respuesta: Se utiliza el método GET.

8. ¿Qué método se usa para enviar información?

Respuesta: Se utiliza el método POST.

9. ¿Qué hace await en esta práctica?

Respuesta: Indica al programa que espere a que la solicitud de red (que toma un tiempo en completarse) se resuelva por completo y devuelva una respuesta antes de continuar con la ejecución de la siguiente línea de código dentro de la función asíncrona.

10. ¿Cómo ayuda fetch a construir una plataforma comunitaria?

Respuesta: Transforma una página web estática en un canal de participación bidireccional vivo. Gracias a fetch, los vecinos pueden leer notificaciones importantes al instante y proponer ideas o reportar necesidades directamente, facilitando un diálogo transparente, ágil y democrático.
