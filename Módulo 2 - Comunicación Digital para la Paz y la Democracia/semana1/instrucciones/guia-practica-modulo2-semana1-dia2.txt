Guía práctica – Módulo 2 Semana 1 Día 2

Actividad:
Fetch: conectar un cliente web con un servidor Express.

Repositorio:
Repositorio dispuesto por el docente.

Importante:
No debes trabajar directamente en main.

Cada estudiante debe crear una rama personal con el formato:

nombres_apellidos

Ejemplo:
maria_gomez
juan_perez
laura_torres_garcia

Evidencia:
La evidencia de esta actividad es únicamente el push de tu rama personal a GitHub.

No debes entregar nada en Moodle.
No debes enviar capturas.
No debes subir archivos adicionales.
No debes publicar enlaces por otro medio.

Comando nuevo del día:
npm install

Pasos obligatorios:

1. Clonar el repositorio

git clone URL_DEL_REPOSITORIO

2. Entrar a la carpeta del proyecto

cd NOMBRE_DEL_REPOSITORIO

3. Crear la rama personal

git checkout -b nombres_apellidos

4. Verificar la rama actual

git branch

La rama marcada con * debe ser tu rama personal, no main.

5. Instalar dependencias

npm install

6. Levantar el servidor

npm start

7. Abrir en el navegador

http://localhost:3000

8. Probar el botón Consultar campaña

9. Probar el botón Consultar avisos

10. Escribir una propuesta en el campo de texto

11. Probar el botón Enviar propuesta

12. Modificar el mensaje de campaña en server.js

13. Detener el servidor con Ctrl + C

14. Levantar nuevamente el servidor

npm start

15. Probar de nuevo el botón Consultar campaña

16. Modificar el texto inicial del textarea en public/index.html

17. Modificar una respuesta visual en public/app.js si el docente lo indica

18. Completar los archivos:

semana4/conceptos-fetch.txt
semana4/bitacora-comando-dia2.txt
semana4/reflexion-comunicacion-fetch.txt
semana4/analisis-mensaje-comunitario.txt

19. Revisar cambios

git status

20. Agregar cambios

git add .

21. Crear commit

git commit -m "Fetch cliente servidor modulo 2 semana 1 dia 2"

22. Publicar la rama

git push -u origin nombres_apellidos
