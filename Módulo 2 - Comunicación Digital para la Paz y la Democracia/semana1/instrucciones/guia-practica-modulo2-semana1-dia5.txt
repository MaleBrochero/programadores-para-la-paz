Guía práctica – Módulo 2 Semana 1 Día 5

Actividad:
Promesas, pruebas, depuración con IA, trazabilidad y guion narrativo final.

Repositorio:
Repositorio dispuesto por el docente.

Importante:
No debes trabajar directamente en main.

Cada estudiante debe crear una rama personal con el formato:

nombres_apellidos

Evidencia:
La evidencia de esta actividad es únicamente el push de tu rama personal a GitHub.

Comando nuevo del día:
npm run prueba

Pasos obligatorios:

1. Clonar el repositorio

git clone URL_DEL_REPOSITORIO

2. Entrar a la carpeta del proyecto

cd NOMBRE_DEL_REPOSITORIO

3. Crear la rama personal

git checkout -b nombres_apellidos

4. Verificar la rama

git branch

5. Instalar dependencias

npm install

6. Levantar la API

npm run prueba

7. Abrir en el navegador

http://localhost:3000

8. Cargar propuestas

9. Enviar propuesta completa

10. Probar validación sin título

11. Probar validación sin mensaje

12. Abrir ruta directa

http://localhost:3000/api/propuestas

13. Revisar public/app.js

Identificar:
fetch
then
catch
respuesta.json()
JSON.stringify

14. Completar conceptos-promesas.txt

15. Completar bitacora-pruebas-api.txt

16. Completar registro-depuracion-ia.txt

17. Completar modelo-datos-message.txt

18. Completar guion-narrativo-final.txt

19. Completar plan-metricas-ciudadanas.txt

20. Completar reflexion-cierre-semana4.txt

21. Revisar cambios

git status

22. Agregar cambios

git add .

23. Crear commit

git commit -m "Promesas pruebas trazabilidad modulo 2 semana 1 dia 5"

24. Publicar rama

git push -u origin nombres_apellidos
