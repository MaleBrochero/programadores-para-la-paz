2. Consumo de la API propia

¿La página usa rutas del mismo proyecto?

Respuesta: SÍ. La aplicación consume exclusivamente endpoints locales y relativos expuestos por su propio servidor (/api/mensajes, /api/calendario, /api/resumen), garantizando total independencia técnica.

3. Mensajes dinámicos

¿Los mensajes aparecen desde datos consultados y no solo desde HTML fijo?

Respuesta: SÍ. El código HTML de index.html contiene divisiones vacías que actúan como meros contenedores receptores, poblándose íntegramente de tarjetas solo cuando JavaScript procesa la consulta de red.

4. Ruta GET /api/mensajes

¿La ruta responde correctamente?

Respuesta: SÍ. Al acceder a ella se despacha con éxito un arreglo en formato JSON conteniendo la totalidad de las propuestas cívicas y sus metadatos asociados.

5. Ruta GET /api/calendario

¿La ruta responde correctamente?

6. Ruta GET /api/resumen

¿La ruta responde correctamente?

Respuesta: SÍ. Entrega un resumen agregado procesado por el backend que cuantifica los elementos totales y las categorías de los mensajes cargados.

7. Respuesta JSON

¿Las rutas entregan datos estructurados?

Respuesta: SÍ. Toda la información es transmitida en formato JSON perfectamente formateado, lo cual posibilita que el cliente interprete y clasifique los datos de forma robusta.

8. Render dinámico

¿El tablero muestra datos recibidos desde la API?

Respuesta: SÍ. JavaScript genera dinámicamente elementos semánticos de tipo article para cada tarjeta, asignándoles clases de maquetación e inyectándolos en el DOM con appendChild.

9. Diagnóstico básico

¿Sabes qué revisar si no carga la información?

Respuesta: SÍ. Se debe verificar el estado activo del servidor de Node.js, inspeccionar la consola de desarrollador del navegador (F12) para descartar errores de solicitud HTTP (p. ej., fallos 404 o 500) y validar la sintaxis de los archivos JSON.

10. Comunicación responsable

¿Los datos dinámicos mantienen claridad, fuente y lenguaje adecuado?

Respuesta: SÍ. Los datos de origen que se inyectan en pantalla cumplen a cabalidad con lineamientos de veracidad, claridad conceptual, citación formal de fuentes y uso de vocabulario no estigmatizante.
