Responde con tus propias palabras.

1. ¿Qué es async y para qué se usa en una función de JavaScript?

Respuesta: Es una palabra clave que se antepone al declarar una función para indicar que dicha función ejecutará tareas de manera asíncrona. Se utiliza para permitir que el código de la función trabaje con operaciones de red o del sistema en segundo plano sin congelar la interfaz del navegador, habilitando obligatoriamente el uso de la instrucción await en su interior.

2. ¿Qué es await y por qué se usa dentro de una función async?

Respuesta: Es una palabra clave de JavaScript que le ordena a una función asíncrona pausar temporalmente su ejecución de línea en línea hasta que la promesa que está esperando (como la respuesta de un fetch) se resuelva o sea rechazada. Se usa para trabajar con datos asíncronos de forma limpia, directa y secuencial.

3. ¿Por qué async y await facilitan la lectura del código en comparación con .then()?

Respuesta: Porque permiten estructurar y leer el código de forma secuencial de arriba hacia abajo, tal como si fuera código síncrono clásico. Elimina la necesidad de anidar múltiples bloques .then() y .catch(), previniendo la complejidad visual y facilitando enormemente las labores de mantenimiento, depuración y comprensión del código por parte de otros programadores.

4. ¿Qué hace el bloque try y catch al consumir una API con async/await?

Respuesta: El bloque try agrupa las instrucciones que queremos intentar llevar a cabo (como la solicitud fetch a la API y el análisis del JSON). El bloque catch actúa como un receptor de seguridad que captura de manera inmediata cualquier error ocurrido dentro de try (por ejemplo, si el servidor está apagado o no hay internet), permitiendo responder de forma controlada sin que la aplicación se rompa.

5. ¿Cómo se relacionan async/await, fetch y el formato JSON en el frontend de una aplicación?

Respuesta: En la interfaz del navegador, una función async realiza una llamada fetch a una API en el servidor. Utilizando await, espera a que se complete la conexión de red y recupere el mensaje. Luego, usa await respuesta.json() para decodificar los datos estructurados en formato JSON y transformarlos en un objeto manipulable de JavaScript para renderizarlo dinámicamente en pantalla.
